# ⚡ Portofolio Modern Sandi Putra Pratama, S.Kom

Portofolio profesional, interaktif, dan modern yang dirancang sesuai dengan referensi desain poster bertema **Hitam, Merah, dan Putih** menggunakan **React 19**, **Vite**, **Tailwind CSS**, dan **Lucide Icons**.

---

## 🎨 Konsep Desain & Estetika UI/UX

- **Background Utama**: Deep Obsidian Black (`#060608` / `#08080b`) dengan canvas partikel rasi bintang interaktif.
- **Watermark Tipografi Raksasa**: Teks merah `PORTFOLIO` di latar belakang hero dengan foto resmi Sandi di lapisan depan.
- **Highlight, Judul & Sub-judul**: Warna merah menyala (`#ef4444` / Crimson) dengan efek glow.
- **Ikon**: Seluruh ikon berwarna **Merah** (`#ef4444`).
- **Teks Penjelasan / Deskripsi**: Seluruh narasi dan teks disajikan dalam warna **Putih bersih** (`text-white`) dengan kontras tajam.

## 💻 Cara Menjalankan Proyek:

```powershell

cd "c:\Portofolio sandi"

# 2. Jalankan server lokal
npm run dev

# 3. Build untuk produksi (hosting)
npm run build
```
